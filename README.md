# spotify-trends-analysis-project
<img width="1275" height="733" alt="image" src="https://github.com/user-attachments/assets/75bc8de7-e013-42f9-8425-632437c8554b" />

This project presents an interactive dashboard built using Power BI to analyze Spotify global music trends, user engagement, and song popularity. The dashboard leverages key metrics such as streams, viral score, trend classification (rising, falling, stable), genre distribution, and artist performance to provide meaningful insights into the music streaming industry.

The analysis highlights patterns in user listening behavior, identifies top-performing artists and genres, and evaluates how engagement metrics influence song success. It also reveals that only a small percentage of songs experience growth, while the majority show declining engagement, indicating a highly competitive market.

Additionally, lifecycle analysis is used to understand how songs perform over time, showing that most songs peak early and gradually decline. The dashboard includes interactive filters that allow users to explore data dynamically across different genres and categories.

Overall, this project demonstrates how data visualization and analytics can be used to uncover trends, support decision-making, and identify key drivers of popularity in the music industry.
